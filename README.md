# Wash N Go Car Wash Management System.

## Project Description
Wash N Go is a  MERN stack car wash management system designed to provide customers with an easy way to learn about services , access car wash memberships, signup for services.

Tha application integrates with EverWash to handle customer membership registration and login. Currently, Wash N Go is working with a  subscription model with EverWash , where membership information and payments are securely managed through them.

The application also provides an admin login system that allow administrators to access a dedicated dashboard for 
Wash N Go operations.


## Features

# Customer Features

 - View Wash N go services

 - View promotional Offers

 - Access membership options

 - Link to signup /login to EverWash.

 - Redirect customers to EverWash Membership services

 - Location and Contact details of the Wash N Go.

 - View Customer Reviews


 ## Admin Features

 - Admin authentication and authorization
